This project uses [Vite](https://vite.dev), React 19, React Router 7 and Vitest (Node 20.19+ required).

## Available Scripts

- `npm start` (or `npm run dev`): runs the app in development mode on [http://localhost:3000](http://localhost:3000).
- `npm test`: runs the tests with Vitest (watch mode; use `npx vitest run` for a single run).
- `npm run build`: type-checks and builds the app into the `build` folder.
- `npm run preview`: serves the production build locally.
